# Memory in Agents:

## Factual Memory:
- Stores factual information about the world, such as facts, events, and knowledge.
- Facts about persons, such as name, age, location, etc.

## Episodic Memory:
- Stores specific experiences or events that an agent has encountered.
- past conversions, interactions, or actions taken by the agent.
- Examples: "Yesterday, I had a conversation with a user about the weather," "Last week, I helped a user find a restaurant."
## Semantic Memory:
- Stores general knowledge and concepts that are not tied to specific experiences.
- Examples: "A cat is a small, domesticated carnivorous mammal," "The Earth orbits the Sun."
